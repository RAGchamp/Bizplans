1. Executive Summary

The problem. Analysts are starting to use AI agents like Claude Code on filings, and in May 2026 Anthropic shipped finance agent templates for this work.1 But a general-purpose agent decides for itself what to read in a 200-page report. Its quality varies from run to run, its figures are not tied to the statements, and its cost is neither known nor controlled. That is acceptable for a first draft. It is not acceptable for analysis a firm acts on, repeated across a coverage list every quarter.

The insight, from a real test. On 8 November 2026 the same question, "Analyze Travelers' commercial insurance business from its 2025 10-K," was answered by a plain Claude Code session and by the RAGchamp Annual Report Analyzer, an agent built on the RAGchamp harness (Plan 18).3 The harnessed agent read only five selected notes in one tool-free call (about 87,000 characters, 78 seconds), and still went deeper: every figure tied to the statements and cited to a page, the reserve triangles quantified, and three real filing anomalies found that the plain session missed. The prompt was saved, so the run can be repeated exactly. Better analysis from less input is the whole business.

The framework. The Annual Report Analyzer is a finished app that answers one kind of question about one kind of document. It will be modified into the RAGchamp agent harness framework: the same tested ingestion, packages, checks and prompt assembly, opened up so an analyst can plug in their own sources, checks, selectors, prompts and output formats, with a cost meter and benchmark runner built in. The Analyzer then becomes the framework's first reference agent.

The product. Agentic AI for Financial Analysts teaches analysts to build agents like that themselves on the framework. The curriculum follows its seven stages: ingest once with deterministic code, check, select only the sources the question needs, confirm, assemble a minimal prompt, analyze, then save, test and measure. Learners build agents for their own industry and workflow in hands-on labs on real filings. Every agent is graded on an Agent Scorecard of quality and cost per analysis, against a plain-agent baseline on the same question.

Business model in one line: analysts pay $495 a year for self-paced labs and the framework starter kits, or $1,495 for a live cohort; a $395 certification proves the skill; research teams pay about $1,800 per seat; and banks and asset managers pay about $150,000 a year for a private academy that builds agents on their own workflows.
Honest verdict: training companies rarely become unicorns, and teaching non-programmers to build agents is harder than teaching them to use one. The plan works only if Claude Code really lets analysts build harnessed agents, if those agents clearly beat plain agents on quality and cost, and if employers buy at scale. It estimates about a 1.5% chance of reaching $1B. The downside is small: Stage 0 costs about $15,000 and six months, and a live cohort course is a realistic $175,000-a-year solo fallback.

2. The Problem — Analysts Use Agents, but Cannot Build Them

An analyst's job is to turn long filings into a defensible view, and to do it again every quarter for every name on the coverage list. A single 10-K can run past 200 pages; the Travelers FY2025 10-K used in this plan's test is 221 pages.3 Agents can now do much of this reading. Three gaps stop analysts from relying on them.

Gap 1: Quality varies

A general agent chooses for itself which pages to read. Two runs of the same question can read different sections, and figures are rarely tied back to the statements or cited to a page.

Fine for a first look. Not for a credit memo or an investment committee.

Gap 2: Cost is unknown

An agent that re-reads a whole filing for each question spends many times the tokens it needs. Across a 40-name coverage list, four quarters and dozens of questions, that adds up, and nobody is measuring it.

In the Travelers test, the plain session's cost was not recorded at all.

Gap 3: Nobody teaches building

AI training for finance teaches prompting and chat. Few courses teach analysts to design an agent: what code should do, what the model should do, what it should see, and how to test and price each run.

So analysts depend on vendors' agents, or on engineers who do not know the accounting.

The real need: analysts know which footnotes matter, which KPIs must be quoted as reported, and what a red flag looks like. Engineers know how to build harnesses. The missing piece is a framework that lets analysts encode their expertise into agents, with Claude Code writing the code, and with quality and cost measured on every run.

4. The RAGchamp Agent Harness Framework

Deterministic first, AI last. Code does everything that has one right answer: finding, extracting, linking and checking. The model does only the judgment, and sees only what that judgment needs.

The framework is built by modifying the Annual Report Analyzer, which already applies this design across 8 report formats, 4 countries and filings from 1968 to 2026.4 In the course, analysts apply the same seven stages to agents for their own questions, industries and documents.

From Annual Report Analyzer to agent harness framework

Today the Analyzer is a complete local web app: an Ingester that builds a Report Package, and an Analyzer with two fixed flows (Identify notes and Analyze non notes) that call the analyst's Claude Code. Its core is already separated the right way: the Analyzer never reads the PDF, prompts are frozen under tests, and every prompt and answer is saved. The modification keeps that core and opens up the parts an analyst needs to change.

The seven stages of a harnessed agent
1. Ingest once

Code reads the filing (PDF or XBRL) into a package: statements, notes, figures, pages. No model, near-zero cost, reused by every question.

2. Check

Code verifies the package: subtotals add up, the balance sheet balances, statement lines link to notes. Errors surface before any model runs.

3. Select sources

A small, cheap model call picks the notes or passages from titles and links, not from the full text.

4. Analyst confirms

The analyst adds or removes sources. Expertise enters here, before money is spent.

5. Assemble minimal context

Selected sources verbatim, plus statements, linked figures, check results and the instructions: verify, cite, quote reported KPIs.

6. Analyze

One model call, no tools, so the model can use only the evidence it was given.

7. Save, test, measure

Prompt and answer saved; prompts frozen under regression tests; quality and cost recorded for every run.

What the analyst builds vs. what the framework provides: the framework supplies the ingestion, package, checks, prompt assembly, cost meter, logging and benchmark runner, all inherited from the Analyzer. The analyst supplies what only they know: which sources answer which questions, which checks matter in their industry, which KPIs must be quoted as reported, and what a good answer looks like. Claude Code writes the glue code.
Agent patterns taught on the framework
Evidence agent

Footnote and statement analysis with page citations and tie-outs. The Annual Report Analyzer's "Identify notes" flow.

Narrative agent

Business, strategy and reported KPIs from Item 1, 1A and MD&A, selected by section instead of read whole. Closes the gap the Travelers test exposed.

Writer agent

Turns evidence and narrative answers into the final memo, under one rule: use only figures that arrived with a citation.

Quarterly agent

Runs the same frozen questions on each new 10-Q or annual report and reports what changed, with the same extraction every period.

Peer agent

Runs one question across a peer set (for example CB, HIG and TRV) from packages built once, so cost grows with questions, not with re-reading.

5. Quality and Cost — The Two Numbers Every Agent Reports

The course's central habit: no agent is "done" until it reports, on a benchmark of real questions, how good its answers are and what each answer costs. Optimizing one without the other is the most common mistake: a cheap agent that misses the anomaly, or an expensive one that reads everything and still cites nothing.

8. Why Now

Agents can now do analyst work

In May 2026 Anthropic launched finance agent templates, including earnings analysis and financial-statement review, as plugins for Claude Cowork and Claude Code.1 The reasoning is good enough; the input, checks and cost control are what analysts must add.

Non-programmers can now build

Claude Code writes, tests and explains code from a brief. An analyst who can specify what an agent should do, and check the result, can now build one. The framework gives them a proven structure to build into.

The harness already exists

The Annual Report Analyzer applies the framework to real filings from four countries, with automatic checks and a regression test suite.4 The course teaches a working system, not a slide deck.

AI spend is under scrutiny

As agent use spreads, firms will ask what each analysis costs and whether it can be trusted. Agents that report both numbers are easier to approve and to budget.

17. Strategic Advantage / Moat

1. A working harness

The RAGchamp harness already reads real filings across 8 formats and 4 countries, with checks and regression tests. Rivals teaching agent building have no proven finance harness to build on.

2. Benchmarks with answer keys

Hand-checked questions on real filings, with planted anomalies and costed baselines. Slow and expensive to copy well.

3. Quality-cost data

Every learner agent run shows which design choices raise quality or cut cost. That data improves the kits and the curriculum.

4. Agents that stay in use

Learners leave with agents they run every quarter. The kits and library keep them subscribed after the course, which is what makes the business behave like software.

5. Certification network effect

Once employers ask for certified agent builders, analysts seek the certificate, which brings more employers.

6. Model-neutral method

Deterministic-first design holds whichever model is best. Better models improve the agents; they do not remove the need to control input, checks and cost.

Honest limit: the framework's ideas are not secret, and a large training brand or AI lab could teach something similar. The moat is the working harness, the benchmarks and the agents learners keep running, and only if they are kept current faster than rivals.

20. Summary

  • Problem: analysts use general agents whose quality varies and whose cost is unknown, and nobody teaches them to build better ones.
  • Evidence: on Travelers' 10-K, an agent built on the RAGchamp harness sent the model only five selected notes in one tool-free call, yet produced deeper, tied-out, page-cited analysis and found three anomalies a plain agent missed, with a saved, repeatable prompt.
  • Framework: the working Annual Report Analyzer, modified into the RAGchamp agent harness framework: its tested core kept, with plug-in checks, selectors and agent definitions, a cost meter and a benchmark runner added. The Analyzer remains as the reference agent.
  • Product: an eight-week curriculum, starter kits, benchmarks and an agent library that teach analysts to build harnessed agents on the framework with Claude Code, graded on an Agent Scorecard of quality and cost against a plain-agent baseline.
  • Business: $495 self-paced, $1,495 cohorts, $395 certification, $1,800 team seats and ~$150k academies; modeled $101.7M revenue in Year 5.
  • Next step: six months of Stage 0, with five kill tests. Kill Test 1, whether harnessed agents clearly beat plain agents on quality at half the cost or less, decides everything.
Bottom line: the framework is real and already demonstrated on a live filing, and the solo fallback is strong. The venture case depends on analysts proving they can build with it, and on turning a course into kits and agents that analysts and employers keep paying for.
